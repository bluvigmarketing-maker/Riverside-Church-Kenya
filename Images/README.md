# Images Folder Guide

Drop your images into the matching subfolder below. Use clear file names (e.g. `pastor-borness.jpg`, `sanctuary-exterior.jpg`) — avoid spaces where possible and prefer `.jpg`/`.png` for photos, `.svg`/`.png` (transparent background) for the logo.

| Folder | What goes here |
|---|---|
| `Logo/` | Church logo — ideally an SVG or transparent PNG, plus a favicon-ready square version if you have one |
| `Homepage/` | Hero/banner images, background photos for the homepage sections |
| `About-Us/` | General "About" imagery not covered by History/Leadership |
| `History/` | Photos illustrating the church's story (old photos, land, tents, construction progress, etc.) |
| `Leadership/` | Headshots/photos of Pastor Borness, Pastor Ezra, and any other leaders or ministry heads |
| `Programs/` | Photos for ministries/programs (Sunday school, youth, worship team, outreach, etc.) |
| `Logo/` (org-specific files, e.g. `women-of-the-living-waters-logo.jpeg`) | Logos for affiliated organizations under the church (each gets its own dedicated page) |
| `Events/` | Photos/flyers for upcoming or past events |
| `Gallery/` | General congregation/worship/community photos for a photo gallery |
| `Contact/` | Map screenshot, building photo, or anything for the contact page |
| `Misc/` | Anything that doesn't fit the above — we'll sort it together |

**Recommended minimums to get started:**
- Logo (transparent background)
- 1–3 strong hero/banner photos for the homepage
- Photos of both pastors
- A handful of general congregation/worship photos

Once these are in place, let me know and I'll start wiring them into the new site.
